# 1. GPT生成モードの追加

## 1.1 既存モード
- [ ] GPTで**1シートずつ生成する既存モード**を残す。
- [ ] 1シートは3×3グリッド、9種類のスタンプ。

## 1.2 新規モード
- [ ] GPTで**5シートまとめて生成するモード**を追加する。
- [ ] 1回の依頼で、3×3のステッカーシートを5枚生成する。
- [ ] 5シートを1枚の巨大な画像にまとめない。
- [ ] **5枚それぞれを独立した正方形画像として生成する。**
- [ ] 5枚まとめて生成することで、同じシリーズ感を保ちやすくする。

---

# 2. 5シート同時生成用プロンプト

- [ ] 「シート1」〜「シート5」を明確に分けて記述する。
- [ ] 各シートに9種類のセリフ・表情・ポーズ・見せ方を入れる。
- [ ] 5枚すべてを同じキャラクター・同じシリーズとして描くよう指定する。
- [ ] 「5セットを1枚のコラージュにまとめない」と明記する。
- [ ] 「5枚それぞれを独立した正方形画像として生成する」と明記する。

---

# 3. キャラクター参照プロンプトの汎用化

- [ ] 添付した参照画像のキャラクターをそのまま使用するよう指定する。
- [ ] 参照画像で確認できる外見・衣装・体の特徴を維持するよう指定する。
- [ ] 5枚すべてで同一キャラクターとして統一する。
- [ ] 各ステッカーにはキャラクターを1体だけ描く。

## 入れないこと
- [ ] RUHiA専用の特徴を共通プロンプトに書かない。
- [ ] 特定の色、衣装、スカーフ、リュック、毛並みなどを固定文として入れない。
- [ ] 参照キャラクターに依存する特徴をテンプレートへ直書きしない。

---

# 4. ステッカー共通条件

- [ ] 各シートは3×3グリッド。
- [ ] 各シートは9種類の異なるステッカー。
- [ ] 正方形（1:1）。
- [ ] 各ステッカーには指定したセリフを1つだけ使う。
- [ ] 各ステッカーは独立させる。
- [ ] 隣のステッカーと接触・重複させない。
- [ ] ステッカー同士の間には十分な隙間を設ける。
- [ ] 背景、背景装飾、影は追加しない。
- [ ] セリフは読みやすく自然に配置する。

---

# 5. 文字・装飾の扱い

## 標準
- [ ] 標準状態では「文字をカラフルにする」を固定しない。
- [ ] 標準状態では「丸みのある太字」など特定の書体を固定しない。
- [ ] 装飾量について細かく指定しない。
- [ ] 星、ハート、汗、効果線などは、モデル側のステッカー表現に任せる。

## 理由
- 以前の生成では、文字がおとなしくキャラクターの可愛さが目立つ仕上がりも良かった。
- 「文字をカラフルに」と指定した生成では、文字が大きく目立ち、視認性の高い仕上がりになった。
- どちらも用途によって使えるため、1種類に固定しない。

---

# 6. 全体の仕上がり設定

モデル固有ではなく、**スタンプ全体の詳細オプション**として扱う。

候補：
- [ ] おまかせ
- [ ] キャラクター重視
- [ ] バランス
- [ ] 文字くっきり
- [ ] 落ち着いた仕上がり

## 方針
- [ ] デフォルトはモデル本来のステッカー表現を活かせる「おまかせ」を基本候補とする。
- [ ] 「文字くっきり」では、文字を目立たせる方向のプロンプトを使う。
- [ ] 「キャラクター重視」では、文字よりキャラクターを主役に見せる方向にする。
- [ ] 「落ち着いた仕上がり」は、ビジネス用途でも使いやすい方向を想定する。
- [ ] 実際にプロンプトで見た目を制御できるか、生成テストで確認してから採用する。

---

# 7. 背景透過

- [ ] 背景透過は**前回仕様の既存要件**として実装する。
- [ ] 今回の新規追加機能として扱わない。
- [ ] GPTは透明背景で生成できる。
- [ ] NanoBananaProでは、透明に見える背景画像になる場合があり、真の背景透過にはならない。
- [ ] そのため、生成後の背景透過処理は実用上重要。

---

# 8. 今回確認できた生成傾向

- [ ] GPTで3×3・9種類のステッカーシートを生成できる。
- [ ] GPTで5シートを1回の依頼でまとめて生成できた。
- [ ] 5シートをまとめて生成した結果、5枚のシリーズ感が揃った。
- [ ] 「文字をカラフルに」と指定すると、文字が目立つ仕上がりになった。
- [ ] その指定がない以前の生成は、キャラクターの可愛さが目立つ仕上がりだった。
- [ ] NanoBananaProでも3×3・9種類のステッカー画像は生成できた。
- [ ] NanoBananaProでは5枚同時生成はできなかった。
- [ ] NanoBananaProでは真の背景透過はできず、透過しているように見える画像になった。
- [ ] NanoBananaProではセリフが勝手に変更されることがある。
