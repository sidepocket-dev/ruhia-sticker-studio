# 経緯の記録

**ここにあるものは仕様ではありません。**

正しい仕様は、リポジトリのルートにある次の3つです。

```text
PRODUCT_SPEC.md   何を作るか
AGENTS.md         どう作るか
TEST_PLAN.md      何を確かめるか
```

ここのファイルは、追加仕様を決めるまでの途中経過です。
内容はすでに `PRODUCT_SPEC.md` へ反映してあります。
**迷ったときは PRODUCT_SPEC.md を見てください。**

| ファイル | 何か | 扱い |
| --- | --- | --- |
| `stamp_generation_improvement_todo_confirmed_only.md` | 会話で確定した追加仕様。まとめて生成・仕上がり設定・背景透過の要件 | 反映済み（§77.22 / §77.24） |
| `stamp_generation_vnext_todo.md` | 上の前段の草案 | **使わない**。画像生成APIを使う前提が混ざっており、本製品の前提と矛盾する |

## `stamp_generation_vnext_todo.md` を使わない理由

本製品は次を守る。この草案はそこと噛み合わない。

```text
ブラウザの中だけで完結する
ユーザーの画像を外部サーバーへ送らない
AI APIを使わない / APIキー不要 / ログイン不要
```

消さずに残しているのは、**なぜその案を採らなかったか**を後から
たどれるようにするため。
